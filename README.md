# Currículum Vitae · Andrés Pino

Currículum web personal hecho **solo con HTML5 y CSS3**, sin frameworks ni JavaScript.

## Qué demuestra este proyecto

**HTML semántico y accesible**
- Estructura con `header`, `nav`, `main`, `aside`, `section`, `article`, `address`, `footer`.
- Enlace "Saltar al contenido", `aria-labelledby`, tabla con `caption`, `scope` y `thead`/`tbody`.
- Elementos nativos como `<meter>` para los niveles y `<details>`/`<summary>` para el mapa desplegable.
- Formulario con validación nativa (`required`, `type="email"`, `minlength`, `autocomplete`).
- Metadatos SEO y Open Graph, y favicon SVG embebido.

**CSS moderno**
- Diseño con **CSS Grid** y **Flexbox**, incluidas rejillas que se adaptan solas con `auto-fit`/`minmax()`.
- **Custom properties** (variables) para todo el sistema de diseño.
- **Modo oscuro automático** con `prefers-color-scheme`.
- Tipografía fluida con `clamp()`, además de `aspect-ratio`, `color-mix()` y `backdrop-filter`.
- Selectores avanzados: `:has()`, `:focus-visible` y `:placeholder-shown` + `:invalid` para validar sin JS.
- Línea de tiempo, comillas y detalles decorativos hechos con pseudo-elementos `::before`/`::after`.
- Transiciones y `@keyframes`, desactivadas con `prefers-reduced-motion`.
- **Hoja de estilos de impresión** (`@media print`): con Ctrl + P el CV sale listo como PDF.
- Diseño responsive desde móvil hasta escritorio.

## Ver el proyecto

Abre `index.html` en el navegador o publícalo con GitHub Pages.
